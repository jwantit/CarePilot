# 웹 호스팅 서비스 기획서 – CarePilot AI

---

## 1. 기획 개요

### 1.1 기획 배경

- **수요 증가**
  - 노인 및 케어가 필요한 대상자 지속 증가
- **효율성 한계**
  - 의료기관의 전화 기반 수동 모니터링 한계
- **데이터 문제**
  - 통화 기록의 비정형 데이터 문제
- **추적 필요성**
  - 케어 대상자 상태를 장기적으로 추적할 시스템 필요
- **기술 접근성**
  - 고령자에게 음성 인터페이스(STT)의 높은 접근성
- **데이터 가치**
  - 의료 음성 데이터를 구조화·분석할 플랫폼 필요

---

### 1.2 기획 목적

- 케어 대상자 상태 수집 자동화
- 음성 데이터를 의료 엔티티로 정형화
- 대상자별 장기 히스토리 구축
- 위험 신호 자동 탐지 및 실시간 알림
- 운영 현황 가시화
- 자연어 질의 기반 AI 비서 제공

---

## 2. 서비스 개요

### 2.1 서비스 정의

CarePilot AI는 다음 기능을 제공하는 **의료 AI 모니터링 웹 서비스**이다.

- AI 기반 케어 대상자 자동 전화 발신
- STT 기반 음성 데이터 수집
- 의료 엔티티 단위 데이터 정형화
- 대상자 히스토리 누적 관리
- 위험 대상자 자동 선별
- 의료기관 직원 대상 실시간 모니터링 제공

---

### 2.2 주요 대상

- 병원 및 의원
- 요양시설
- 보건소 및 지자체
- 수술 후 관리 조직
- 만성질환 관리 기관

> ※ **의료기관 직원만 회원가입 가능**

---

### 2.3 사용자 권한 체계

| 구분 | 설명 |
|---|---|
| 운영자 | 시스템 전체 관리 권한 (서비스 제공자) |
| 관리자 | 업체 등록 및 직원 승인 권한 |
| 유저 | 일반 직원 (의료시설 직원) |

---

### 회원가입 프로세스

1. 관리자가 업체 등록
2. 일반 직원이 업체번호 입력 후 회원가입
3. 관리자에게 승인 요청 메일 발송
4. 관리자가 승인
5. 일반 직원 로그인 가능

- 단순 콜봇이 아닌 **의료 데이터 정형화 중심 서비스**
- 음성 기반 상태 수집 특화
- 장기 히스토리 기반 위험 관리
- 실시간 운영 가시성 제공

## 6. 결론

CarePilot AI는 의료 음성 데이터를 구조화하여  
케어 대상자 히스토리를 기반으로 위험 대상자를 선별하고,  
의료기관 직원에게 **즉시 대응 가능한 정보와 인사이트**를 제공하는  
**의료 AI 모니터링 웹 서비스**이다.
